# London Eco-Rider: Ice Cream & Bottle Patrol

🏆 **Winner of the GopherCon UK 2026 Mini Game Jam**  
**Author**: Ivan S ([@inesusvet](https://github.com/inesusvet))

**London Eco-Rider: Ice Cream & Bottle Patrol** is a fast-paced 2D side-scrolling platformer built with Go and Ebitengine v2. Players control Leo, an energetic young boy riding his bicycle through downtown London past iconic landmarks like Big Ben, red telephone boxes, and double-decker buses.

## 🚲 Gameplay & Objective

- **Collect Ice Cream Cones**: Gain instant score bonuses and temporary Turbo Speed Boosts!
- **Collect Plastic Bottles**: Fill the Eco-Recycling Meter to trigger Eco-Fever Mode (double points + invincibility).
- **Avoid Hazards**: Dodge black cabs, double-decker buses, construction cones, potholes, and pigeons!

---

## 🎮 Controls

| Action | Keyboard Input | Gamepad Input |
| :--- | :--- | :--- |
| **Move Left / Right** | Arrow Keys or `A` / `D` | D-Pad Left / Right |
| **Jump / Bunny Hop** | Spacebar / Up Arrow or `W` | Button A |
| **Turbo Boost** | Left Shift or `J` | Button X |
| **Pause** | `Escape` or `P` | Start |

---

## 🚀 Quick Start

### Run Desktop Game

```bash
go run ./cmd/game
```

### Run Local Web Server (WASM)

```bash
go run ./cmd/server
```
Then navigate to `http://localhost:8080` in your browser.
